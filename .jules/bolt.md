## 2026-08-14 - Memoization in High-Frequency Telemetry Data Streams\n**Learning:** High-frequency rendering scenarios (like live OBD telemetry rendering every 800ms) can quickly expose un-memoized string operations and list filtering (like `Array.prototype.filter` combined with `String.prototype.toLowerCase()`) as significant main-thread blockers.\n**Action:** Always wrap data transformations inside `useMemo` and extract expensive operations (like `toLowerCase()`) outside the loop when dealing with state updates driven by frequent intervals or streaming data sources.
