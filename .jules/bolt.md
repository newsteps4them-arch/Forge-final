## 2024-05-14 - React.memo Optimization
**Learning:** Found multiple pure React components that are frequently rendered during top-level re-renders without React.memo. Added React.memo to prevent unnecessary child re-renders. When applying `React.memo`, it is critical to avoid wrapping components that receive unmemoized callback props (e.g., `BottomNavBar`, `TopStatusBar`), as reference changes render the memoization ineffective. Do not use custom `areEqual` functions to ignore these callbacks, as it introduces stale closure bugs. Target components with no props or strictly stable props (e.g., `NotificationContainer`).
**Action:** Always consider `React.memo` for presentation components with stable props like NotificationContainer to skip expensive tree reconciliation during state updates on the parent component.
